Why another window over Claude Code

The real CLI, not a copy

Every message goes through the Claude Code you already installed and signed in to. Same slash commands, same sessions. Your usage is billed by Anthropic to your own account.

One window per project

Each project is a tab, or its own window. Switch project and the sessions, browser, files and layout switch with it.

Nothing is lost on restart

Sessions resume on launch. A small host process outlives the windows, so closing one costs you nothing.

01 · Chat

A chat over the real Claude Code

Type, send, read. Code blocks, a diff per turn, drag-in screenshots, @ for files, / for commands. The session ids are Claude Code's own, so claude --resume in a terminal picks up where the chat left off.

02 · Sandboxes

Most prompts are throwaway. Treat them that way.

⌘N starts a new chat in a sandbox folder, no setup. Keep it, promote it to a real folder when it turns into something, or let it archive itself after two idle weeks.

03 · Projects

Projects in windows, across displays

Every window carries a strip of projects. Drag a tab out to put a project on its own display; drop it on another window's strip to move it. Windows, bounds and layouts are restored on launch.

04 · Permissions

All six permission modes, Bypass included

Ask first, Accept edits, Auto, Don't ask, Plan only, Bypass. Set per session from the message box, shown on the session row. Bypass is marked red and confirms once per project.

05 · Panels

Files, browser, diff and terminal, one panel

⌘J opens the right panel: a file tree with preview, the diff of what the last turn changed, a browser with its own cookies per project, and a real terminal in the project folder.

06 · Attention

Nothing waits on you silently

A session that needs an answer rises to the top of the sidebar and counts on the Dock badge. Answer a permission with 1, 2 or 3. ⌘⇧U jumps to the next one waiting.

Keyboard-first

One shortcut table. Every key is in it.

The app, the menus and Settings all read the same list, so a shortcut you see in a tooltip is the one that works. The full table lives in Settings → Shortcuts.

FAQ

Short answers

Does it run on Windows or Linux?
No. macOS on Apple Silicon only, today. Nothing else is planned for the first version.
Do I need an API key?
Not for Claude. Bring your own Claude Code: {{PRODUCT_NAME}} runs the Claude Code you already installed and signed in to. Your usage is billed by Anthropic to your own account. Gemini: use a Gemini API key (recommended by Google). {{PRODUCT_NAME}} also includes a terminal for any CLI you have installed.
What about Gemini?
Use a Gemini API key (recommended by Google) with the Gemini CLI. The Gemini pane in {{PRODUCT_NAME}} is a built-in terminal that runs the CLI you installed, gemini or Antigravity's agy. Chat rendering for Gemini comes after Claude's.
Do I need an account?
No. There is no {{PRODUCT_NAME}} account, no sign-up and no server. {{PRODUCT_NAME}} never asks for provider credentials; each CLI keeps its own.
Where does my data live?
In {{DATA_DIR}}: a SQLite database with projects, sessions, windows and settings, plus before/after snapshots of the files each turn touched. Transcripts stay in {{CLAUDE_DIR}}, where Claude Code keeps them.
Why does macOS warn when I open it?
Current builds are local and not signed, so Gatekeeper warns the first time. Right-click the app and choose Open. Signed and notarised releases, with auto-update, are the next step.
